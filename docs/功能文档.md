# 拍鸟图鉴 · 功能文档

> 本文档描述应用**当前已经具备的功能**，面向使用者与产品视角：只讲「能做什么、怎么用、有什么规则」，不涉及实现方式。
> 对应产品：桌面应用「拍鸟图鉴」（bird-atlas）。

---

## 1. 应用定位

把拍到的照片整理成一本可以翻阅、统计、收集，还能做成动物卡的**个人图鉴**：

**导入照片 → 录入物种 → 自动补全资料 → 指派照片 → 生成动物卡 → 统计与成就**

| 模块 | 作用 |
| --- | --- |
| 图鉴墙 | 浏览、检索、筛选全部已收录物种 |
| 物种详情 / 录入编辑 | 维护物种资料，自动抓取 + 手动补录 |
| 导入待分类 | 扫描本地图库，把照片指派给物种 |
| 卡组（动物卡） | 自动生成卡片、卡组册、批量导出 |
| 卡片编辑器 | 图层级微调卡面与卡背，保存模板 |
| 卡片详情 / 打印视图 | 3D 看正反面、数值溯源、导出与拼版 |
| 拍摄统计 | 热力日历、月度节奏、装备战绩、分布排行 |
| 足迹地图 | 拍摄地点可视化与照片下钻 |
| 成就墙 / 想拍清单 | 收集目标与长期激励 |

---

## 2. 界面总览

**顶部导航**：`图鉴墙` `卡组` `足迹地图` `拍摄统计` `成就` `想拍清单` `导入待分类`，右侧为 `录入物种` 快捷入口。

**底部状态栏**：本地引擎状态（`运行中` / `未连接`）、物种 / 照片 / 卡片 / 地点数量、`正在扫描` 提示、`上次导入` 时间、`连续` 打卡天数，以及当前是否 `查看照片中`。

**运行形态**：分 `桌面模式` 与 `浏览器模式`。桌面模式支持导出与打印；浏览器模式适合浏览、录入与整理，状态栏会标出当前模式。

**通用表现**
- 数据读取失败时给出明确提示（如「请确认本地服务正在运行」）并可重试，不会白屏。
- 空态均有引导语与跳转按钮（`导入待分类`、`去指派照片`、`录入物种` 等）。
- 系统开启「减少动态效果」时，3D 旋转等动画降级为静态展示。

---

## 3. 图鉴墙

**概览**：物种数、照片数、地点数、连续打卡、五星照片等指标。

**筛选条**（可一键 `重置筛选`）
- 关键词：按 `中文名` / `学名` / `别名` 搜索
- 分类：`全部类群` → `全部目` → `全部科` 三级联动
- 保护级别、栖息地
- 器材：`全部机身` / `全部镜头`
- 状态：`只看收藏` / `只想拍`
- 排序：`名称排序` / `最近拍摄` / `首次记录` / `照片数量` / `稀有星级`

**视图切换**：`卡片墙` 与 `日志流` 两种浏览方式，筛选条显示当前命中的物种数量。物种卡片展示头图、中文学名、星级、照片张数、稀有度等要点，可进入详情，也可就地收藏或加入想拍。

---

## 4. 物种详情

**资料区**
- 头图、完整资料面板、分类（纲 / 目 / 科）、生态型、居留型
- 保护级别、IUCN 等级、是否「三有」名录
- 栖息环境标签、形态数据量规条（体长 / 体重 / 翼展等）
- 中英双语简介、星级与稀有度、资料完整度
- 缺失信息会明确标注（`学名待补录`、`地点待补录` 等），提示可补全

**照片记录**：照片张数、`首次` / `最近` 拍摄时间、使用的机身信息、照片网格与刷新；无照片时提供 `去指派照片`。

**我的卡片**：显示已制作卡片数量与编号状态（`未编号` / `尚未制卡`），可直接进入编辑器逐层微调。

**可执行操作**
- `收藏` / `已收藏`
- `加入想拍` / `移出想拍`
- `编辑资料`、`制作卡片`
- `删除物种`：删除前明确说明影响 —— 名下照片退回待分类池、已制作卡片一并删除、**原始照片文件不会被删除**（只解除关联），并提示如需保留卡片请先在卡组页导出。

---

## 5. 录入与编辑物种

**入口**：顶部 `录入物种`、图鉴墙录入、待分类池的 `新建物种并录入`。从待分类跳转时会用所在词条名预选维基候选。

**三种资料获取方式（可混用）**
1. **维基候选补全**：随输入逐键防抖检索，界面提示检索会访问外网，不必每个字符都发请求。
2. **抓取预览**：先展示抓到的词条预览，确认后填入名称、分类、保护级别、形态量规与中英双语简介；填好后仍可修改，`保存后以你的版本为准`。
3. **手动补充**：任何字段都能自己填；抓取不到的字段（拍摄习惯、稀有度自评、想拍理由等）靠手动补录。

**表单字段分组**
- **物种资料**：中文名（必填，为空时提示「先填写一个中文名再保存」）、学名、别名、分类、生态型、居留型等
- **简介与分布**：决定动物卡「效果框」的内容
- **形态数据**：决定详情页量规条
- **保护级别**：影响卡片星级与稀有度加成（国家一级 / 二级 / 三有名录、IUCN 等级）
- **想拍设置**：可写入期望的季节、地点与想拍理由 —— 没拍到的物种也能先加入想拍清单
- **待指派照片**：保存后自动指派所选照片
- 资料完整度条实时提示「补全越多，卡片与统计越准确」

**保存方式**：`保存修改` 或 `保存并进入详情`；保存后立即同步到图鉴、统计与卡片候选，并可一键 `去制作动物卡`。

## 6. 导入待分类

**图库目录**
- 把一个或多个常用拍摄目录加入图库，点 `开始扫描`
- 明确说明：**扫描只建立索引，不移动也不复制原图**
- 进度实时更新，扫描期间可继续筛选其他照片
- 结果分类统计：`新导入` / `重复跳过` / `失败` / `已指派`
- 支持 `刷新` 与 `校验原图`（报告 `缺失` 的文件）
- 指派物种后照片自动进入图鉴、统计与卡片候选

**待分类池**
- 缩略图浏览，带 EXIF 徽章（机身、镜头、焦段、拍摄时间等）
- `快捷评分`：挑片时先给好照片打五星，制卡会优先选中五星照
- 勾选多张 → `指派给物种`：可搜索已有物种（中文名 / 学名），也可 `新建物种并录入`
- 提示：物种封面与首次记录按拍摄时间自动计算
- `加载更多` / `已加载全部`

**删除记录**：只移除索引，原图保持不动；下次扫描该目录时照片会重新出现在待分类池；从图鉴移除照片同样只解除关联。

## 7. 动物卡：自动生成规则

每张卡都由「物种资料 + 拍摄记录」自动生成，默认采用推荐属性、星级与数值，可随时进入编辑器微调。

**属性（八属性）**：`林` `泽` `原` `海` `山` `空` `夜` `都`。判定优先级：科别特征 → 生态型（涉禽 / 游禽 / 猛禽 / 陆禽 / 鸣禽）→ 栖息地标签。

**星级（1–10，含半星）**：`IUCN 基础分 + 保护级别加成 + 记录次数修正 + 首次记录 +1 + 想拍达成 +1`
- 记录次数修正：1 张 +2；2–3 张 +1；10 张及以上 −1
- 编辑器内可查看星级来源明细，也可按最新数据 `重算`

**珍稀值（对应 ATK）**：`星级 × 300 + 保护加成（国一 500 / 国二 300）− 记录惩罚（每张 50，最多计 6 张）`，范围 0–4000

**记录值（对应 DEF）**：`照片数 × 120 + 五星照片 × 200 + 资料完整度 × 800 + 行为照 300`，范围 0–4000

**稀有度**：`N` → `R` → `SR` → `UR` → `LEGEND`，按星级阈值（4 / 6 / 8 / 10）判定；开启闪膜时低星卡也可获得提升。

**卡号**：自动编号 `BA-0001` 起；删除卡片后卡号会被释放。

**卡面文本**：称号、卡名、类型行、物种简介、拍摄记录、卡背文字。容量受「效果框合计上限（140 字）」与每行字数上限约束，超限以红字标出，并提供 `自动精简`、`按句截断`、`移除括号内容`。

**卡背**
- **底纹主题**：多种底纹可选，可整体 `更换卡背主题`
- **纹章**：羽毛 / 光圈 / 枝叶 / 山峦 / 水波 / 罗盘等，可关闭为「无纹章」
- **弧形文字**：如「拍鸟图鉴」「摄于野外」「本地收藏」
- **镜头印花（8 种元件，独立开关）**：光圈叶片（片数与相位）、焦段刻度环（可标注等效焦距）、卡口三爪、胶片齿孔、取景框角标、快门帘幕（密度可调）、微缩文字环（可编辑文字）、机身剪影（单反 / 微单）
- **印花色调**：暗金 / 枪灰 / 苔绿；**印花强度**整体可调
- 卡面另可切换 `闪膜`（镭射碎光）与 `显示学名`

## 8. 卡片编辑器

三栏布局：左侧图层与自由元素、中间画布实时预览、右侧检查器。

**图层**
- 正面图层组 + 卡背图层 + `自由元素`（文本 / 贴纸 / 水印）
- 每层可 `显示 / 隐藏`、`锁定 / 解锁`、调整层级顺序、单独重置
- 图层面板可拖动图层名定位微调，选中后画布同步高亮

**检查器可调项**
- 位置（水平 / 垂直偏移）、缩放、旋转
- 颜色：跟随预设或自定义，可清除
- 字体：字号（可回退基准）、字重（常规 / 中等 / 半粗 / 粗体 / 特粗）、对齐、字距、斜体
- 效果：渐变文字、文字阴影（深色卡面的可读性保险）、描边（浅色背景的暗边）
- 不透明度
- 四级重置：`重置本层` / `重置整组` / `重置卡面微调` / `重置卡背`

**文本工具**
- 实时字数计数与超限红字；全部在容量内时提示 `所有文本都在容量上限内`
- `自动精简`（按维基导语精简）、`按句截断`、`移除括号内容`
- 一键 `恢复自动卡名` / `恢复自动类型行` / `恢复自动文本`
- 可编辑称号、卡名、类型行、物种简介、拍摄记录、卡背文字

**自由元素**
- 新增文本层（签名 / 日期 / 标语）、贴纸层、水印层
- 位置锚点：居中 / 卡片中心 / 贴底 / 右下角
- 混合模式：正常 / 滤色 / 提亮 / 正片叠底 / 叠加；支持投影与透明度
- 本地贴纸库：上传透明底图片（有尺寸与体积限制），入库后可在任意卡面复用
- 自由元素有数量上限，达到上限会提示先删除不用的再添加

**数值与卡图**
- 查看属性、星级与来源明细、稀有度、珍稀值、记录值；可手动 `修改属性` / `修改稀有度` / `调整星级`，或一键 `重算`
- 卡图候选缩略图点击即替换；`裁切` 支持竖幅取景、水平 / 垂直取景与放大
- 可选 `待分类` 照片；物种尚无照片时卡面使用占位图

**预设与模板**
- `预设模板`：多套卡面预设（蜜金、苔影、羽青等）可整体切换
- `我的模板`：把调好的卡面 `存为模板`（保存数据库里的最终样式，未保存时会先自动保存），之后在任意卡片一键 `套用`，也可 `删除`
- 首次保存自定义模板会解锁成就「卡牌设计师」

**画布与操作**
- 画布缩放、`网格` 与 `参考线区域` 开关（对齐提示）
- 图层可拖拽微调，也可用方向键按固定步进微调
- 卡片比例恒定锁定；画布宽度同时受缩放与可用高度约束，保证整张卡始终完整可见
- 预览支持 `正反面` 切换与 3D 拖拽旋转、双击翻面
- `撤销` / `重做`（所有调整进入撤销栈，保留固定步数）、`复制为新版本`、`保存`
- 有超限文本会提示「还有超限文本」；有未保存改动时导出会被提醒先保存

## 9. 卡组页

**概览指标**：卡片总数（含全部稀有度）、稀有度分布、属性覆盖（八属性中已出现的种类）、类群覆盖。

**卡组册**：用于归组卡片，可查看最大卡组；尚未创建时会给出引导。

**卡片墙**
- 筛选：`全部稀有度` / `全部属性`
- 排序：`最新` / `星级` / `卡号` / `最近制作`
- 卡片悬停抬升，点击进入详情查看正反面与导出
- 提供 `重置筛选`，并显示当前筛选命中的卡片数量

**生成动物卡**
- 从下拉按中文名搜索、支持首字快速过滤选择物种
- 自动采用推荐属性、星级、数值，并调用卡面摘要生成简介
- 生成后自动统计该物种照片数与五星照片数，用于计算记录值与完整度加成；没有照片也能先生成，之后再回来切换卡图
- 可选 `生成并进入编辑器` 继续微调

**批量导出**：可对当前筛选结果发起批量导出。

## 10. 卡片详情与打印视图

**卡片详情**
- 显示单张卡片的正反面；提示 `拖拽卡片可以旋转查看厚度与高光`、`双击翻面`、`滚轮缩放`
- 卡片宽度同时受列宽与窗口高度约束，短窗口下也能看完整张卡
- **数值与来源面板**：星级（自动）、属性、珍稀值、记录值、卡图（含机身信息）、卡背主题（含纹章）、物种资料（照片数、中文简介），并逐项展示数值来源
- 操作：`进入编辑器`、`导出卡背`、`删除卡片`
  - 删除只影响这张卡片，物种资料与照片都会保留
  - 删除后卡号释放，成就进度按实际留存卡片重新统计
  - 如需保留素材，界面会建议先导出

**打印视图**：无导航、无页面内边距的纯净渲染视图，尺寸严格等于所选档位像素，专用于导出截图与 A4 拼版；导出时按实际卡图窗口像素取原始图切片，保证放大不糊。

## 11. 导出与打印

**尺寸档位**（用途不同，等比放大同一套版式）

| 档位 | 用途 |
| --- | --- |
| XS | 卡组墙缩略 |
| S | 列表与侧栏 |
| M | 卡片详情 |
| L | 导出标准 |
| XL | 高清导出 |
| PRINT | 打印拼版源图 |

**导出选项**
- `导出面`：正面 / 背面
- 单卡导出 PNG；卡组页支持批量导出
- A4 拼版：每页 3 × 3 布局，可选 `裁切角标`、`双面镜像`（用于双面打印对齐）、可选 `出血`（四周留边，便于裁切）
- `调试背景`：以深色底导出，便于检查边界与透明区域
- 导出使用编辑器里保存的最终样式：有未保存改动时会先提醒保存，避免导出旧样式

## 12. 拍摄统计

- **概览**：物种数、照片数、地点数等统计口径说明（`统计口径`）
- **热力日历**：点击任意一天可翻出当天所有照片；含 `活跃`、`连续打卡`、`最长连续`、`五星照片` 指标
- **月度节奏**：按月看出片节奏
- **装备战绩**：机身与镜头分别统计出片量与覆盖物种数（`镜头战绩` / `按镜头统计出片量与物种数`）
- **分布排行与地点榜**：`目级分布`（按目统计已收录物种）、`保护级别覆盖`（国家重点保护与三有名录占比）、`栖息地构成`（按栖息标签统计）、`地点榜`（出片最多的拍摄地点）
- **最近解锁**：展示成就进展，可直接 `查看成就墙`
- 各区块均有空态引导（如地点榜提示「照片带定位或指派到地点后这里会生成排行榜」）

---

## 13. 足迹地图

- **底图**：离线世界轮廓（无需联网），`滚轮缩放`、`拖拽平移`
- **拍摄气泡**：气泡大小代表该地点的出片量与物种数，点击气泡可翻出那里拍到的照片
- **栖息地筛选**：`全部栖息地` 下拉，切换后地图与统计同步过滤
- **地点清单**：按出片量排序，点击与地图联动，支持 `下钻查看`，并可 `在…打开坐标`（在地图服务中查看）
- **未定位补录**：把没有 GPS 信息的照片手动补录到地点，补录后气泡即会亮起
- **概览**：地点数、照片数、物种数
- 空态引导：提醒导入带定位的照片，或在右侧把无定位照片补录到地点

## 14. 成就墙

共 **43 项成就**，分为 **9 个分组**，每项徽章分四档：铜 / 银 / 金 / 传说。

**界面能力**

## 15. 想拍清单

把还没拍到的目标物种先记下来，形成一份可勾选的拍摄任务。

**界面能力**
- **目标卡网格**：每张目标卡上的进度环表示是否已经拍到；悬停卡片可 `标记达成` 或 `移出清单`
- **概览**：`目标` 总数、`已达成` 数、`达成率`、清单物种的累计照片数，并可跳转 `看足迹分布`
- **筛选**：`全部` / `待拍` / 已达成
- **新增目标物种**：可直接新建一个目标物种并录入

**达成规则**
- 把拍到的照片指派给该物种，想拍即视为达成，进度环自动点亮，并计入成就进度
- 达成时间取照片的**最早拍摄时间**，方便回溯是哪次外拍完成了目标
- 在物种详情页点 `加入想拍` 即可加入清单；录入物种时打开「加入想拍清单」，可顺便写下期望的季节与地点、想拍理由

## 16. 数据与隐私

- **全部数据保存在本地**，不依赖云端账号；应用离线即可浏览图鉴、统计与卡片。
- **照片只建立索引**：扫描与导入都不会移动、复制或修改原始照片文件。
- **删除即解除关联**：删除物种、删除卡片、删除照片记录都只影响图鉴内的数据，磁盘上的原图保持不动（界面在每次删除前都会明确说明）。
- **资料抓取**：仅「维基候选补全 / 抓取预览」需要联网，抓取失败可随时改用手动补充，不影响其他功能。
- `浏览器模式` 适合浏览、录入与整理；导出与打印在 `桌面模式` 下提供。

## 17. 使用边界说明

- 维基抓取受外部词条质量影响，可能的缺项（学名、形态数据、保护级别等）需要在编辑页手动补录；界面会用「待补录」明确标出。
- 没有 GPS 信息的照片不会出现在地图气泡上，需要在足迹地图中手动补录地点。
- 卡片数值与星级是按规则的**自动推荐值**，可随时在编辑器里手动调整；调整后不会反向改写物种资料。
- 删除已制作的卡片后，如需重新收集，可在卡组页重新生成（卡号会重新分配）。
- 资料完整度、五星照片数、行为照等会直接影响卡片数值，补齐资料能让统计与卡片更准确。
